# LogTrawl - 专业日志分析工具

LogTrawl 是一个基于 Wails v2 框架开发的现代化桌面日志分析工具，提供强大的日志查看、搜索、过滤和分析功能。

## 功能特性

- **多格式日志支持**: 支持各种日志格式的解析和语法高亮
- **高级搜索**: 支持正则表达式、大小写敏感、全词匹配等搜索模式
- **实时过滤**: 基于模式创建过滤视图
- **语法高亮**: 可自定义的语法规则和颜色
- **时间线追踪**: 追踪重要的日志条目
- **多文件支持**: 同时打开和分析多个日志文件
- **导出功能**: 导出过滤结果和分析报告

## 技术栈

- **后端**: Go + Wails v2 框架
- **前端**: Vue 3 + TypeScript + Element Plus + Pinia
- **桌面**: 跨平台桌面应用程序

## 快速开始

### 开发环境

1. 确保已安装 Go 1.21+ 和 Node.js 16+
2. 安装 Wails CLI:
   ```bash
   go install github.com/wailsapp/wails/v2/cmd/wails@latest
   ```

3. 克隆项目:
   ```bash
   git clone <repository-url>
   cd LogTrawl
   ```

4. 安装依赖:
   ```bash
   cd frontend
   npm install
   cd ..
   ```

5. 运行开发模式:
   ```bash
   wails dev
   ```

### 构建生产版本

```bash
wails build
```

构建完成后，可执行文件位于 `build/bin/` 目录下。

## 使用指南

### 打开日志文件

1. **单个文件**: 点击左侧边栏的"打开文件"或使用工具栏的文件按钮
2. **文件夹**: 点击"打开文件夹"批量导入日志文件
3. **最近文件**: 从左侧边栏的"最近打开"列表中选择

### 搜索和过滤

1. **基本搜索**: 在顶部搜索框中输入关键词
2. **高级搜索**:
   - 点击 `.*` 启用正则表达式
   - 点击 `Aa` 启用大小写敏感
   - 点击 `Ab` 启用全词匹配

### 查看选项

- **行号显示**: 通过视图菜单切换
- **语法高亮**: 自动识别日志格式并高亮显示
- **自动换行**: 适应窗口宽度

### 导出功能

1. 打开日志文件
2. 应用所需的过滤器
3. 点击工具栏的导出按钮
4. 选择保存位置和格式

## 支持的日志格式

- Apache/Nginx 访问日志
- 应用程序日志 (INFO/WARN/ERROR)
- 系统日志
- 自定义格式日志

## 快捷键

- `Ctrl+O`: 打开文件
- `Ctrl+F`: 搜索
- `Ctrl+E`: 导出
- `F5`: 刷新当前文件
